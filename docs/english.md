# 영어 학습실

영어의 어휘·문법·독해·작문을 단계적으로 정리하는 공간이다. 규칙을 외우는 데서 끝내지 않고 문장 속에서 쓰임을 확인한다.

## 학습 영역

### 1. 어휘
- 단어의 기본 의미와 문맥에 따른 의미를 함께 기록한다.
- 품사, 자주 쓰이는 결합 표현, 예문을 정리한다.
- 비슷한 뜻의 단어는 쓰임의 차이를 비교한다.

### 2. 문법
- 문장 성분과 기본 어순
- 시제와 조동사
- 수동태와 준동사
- 관계사와 접속사
- 가정법과 비교 표현

### 3. 독해
1. 문장의 주어와 동사를 먼저 찾는다.
2. 수식어와 절의 범위를 구분한다.
3. 연결어를 통해 글의 논리 구조를 파악한다.
4. 문단의 중심 내용과 글쓴이의 주장을 요약한다.

### 4. 작문과 말하기
배운 문법과 어휘를 활용해 짧은 문장을 직접 만들고, 어색한 표현은 문맥과 문법 근거를 확인해 수정한다.

## 오답·표현 기록

| 항목 | 기록 |
|---|---|
| 표현 | 새로 배운 단어·구문 |
| 의미와 쓰임 | 문맥에 맞는 뜻과 문법 |
| 예문 | 직접 만든 문장 |
| 실수 | 틀린 이유 |
| 복습 | 다시 확인할 날짜 또는 단원 |

**학습 원칙:** 단어의 뜻 하나만 외우지 말고 품사·문맥·함께 쓰이는 표현을 확인한다.
