# 한국사 학습실

한국사의 시대 흐름과 핵심 사건을 공부하고, 사료를 바탕으로 역사적 사실과 해석을 구분하는 학습 공간이다.

## 학습 순서

1. **시대 흐름 파악하기**: 선사 시대부터 현대까지 주요 변화를 연표로 정리한다.
2. **정치·사회·경제·문화 살펴보기**: 한 시대를 여러 영역으로 나누어 이해한다.
3. **사건의 원인과 결과 분석하기**: 사건을 단순 암기하지 않고 배경과 영향을 연결한다.
4. **사료 확인하기**: 사료의 작성 주체·시기·목적과 한계를 검토한다.

## 학습 기록 양식

| 항목 | 기록할 내용 |
|---|---|
| 주제 | 공부한 시대·사건·인물 |
| 핵심 사실 | 사료나 신뢰할 수 있는 자료로 확인한 사실 |
| 원인과 전개 | 사건이 발생하고 전개된 과정 |
| 결과와 영향 | 당대와 후대에 미친 변화 |
| 남은 질문 | 추가로 확인할 쟁점과 자료 |

**학습 원칙:** 연도와 인물 이름만 외우기보다 사료와 연구 성과를 확인하고, 확실한 사실과 해석을 구분한다.
