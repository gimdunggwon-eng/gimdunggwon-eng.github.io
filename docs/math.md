# 수학 학습실

수학 개념을 정의와 성질에서 출발해 문제 해결 과정으로 연결하는 학습 공간이다.

## 학습 순서

1. **정의 이해**: 용어가 정확히 무엇을 뜻하는지 확인한다.
2. **성질과 공식 정리**: 공식이 성립하는 조건과 적용 범위를 함께 기록한다.
3. **예제 분석**: 풀이의 각 단계가 왜 가능한지 설명한다.
4. **유형별 연습**: 기본 문제에서 응용 문제로 확장한다.
5. **오답 점검**: 계산 실수와 개념 오해, 조건 누락을 구분한다.

## 문제 풀이 기록 양식

| 단계 | 기록할 내용 |
|---|---|
| 조건 | 문제에서 주어진 정보 |
| 목표 | 구해야 하는 값 또는 증명할 내용 |
| 개념 | 사용할 정의·정리·공식 |
| 풀이 | 근거가 드러나도록 단계별로 전개 |
| 검산 | 계산과 조건을 다시 확인 |
| 정리 | 다른 문제에도 적용할 핵심 아이디어 |

## 개념 정리 원칙

- 공식만 적지 말고 기호의 의미와 성립 조건을 기록한다.
- 풀이 과정을 생략하지 않고 논리적 연결을 확인한다.
- 틀린 문제는 정답을 옮기는 대신 오류가 발생한 원인을 적는다.

**학습 원칙:** 답이 맞는지뿐 아니라 풀이의 각 단계가 타당한지 설명할 수 있어야 한다.
