## 🤖 J.A.R.V.I.S. — AI 음성 비서

Python과 로컬 AI를 이용해 직접 개발하고 있는 개인용 AI 비서 프로젝트.

음성으로 명령을 내리고, AI가 응답하며, 직접 음성으로 말하는 나만의 JARVIS를 만드는 것이 목표야.

### 주요 기능

- Ollama 기반 로컬 AI 모델 연결
- Qwen2.5:3b를 이용한 AI 대화
- Faster-Whisper 기반 음성 인식
- `Hey Jarvis` 호출어 감지
- TTS를 이용한 음성 출력
- CustomTkinter 기반 GUI
- 메모장 및 계산기 실행 기능

### 개발 기록

이 프로젝트는 처음부터 완성된 것이 아니야.

OpenAI API 사용 문제부터 로컬 AI 전환, 마이크 입력 오류, 음성 인식 문제, TTS 설치와 속도 개선, GUI와 Python 모듈 통합까지 여러 시행착오를 거치며 개발하고 있어.
