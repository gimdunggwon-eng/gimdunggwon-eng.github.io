# 과학 학습실

과학의 개념과 원리를 관찰·실험·자료 해석을 통해 이해하는 학습 공간이다.

## 과학 학습 방법

1. **현상 관찰**: 무엇이 관찰되는지 구체적으로 기록한다.
2. **질문 설정**: 관찰한 현상에 대해 검증 가능한 질문을 만든다.
3. **가설과 변인**: 독립 변인·종속 변인·통제 변인을 구분한다.
4. **자료 수집**: 실험이나 신뢰할 수 있는 자료에서 결과를 얻는다.
5. **분석과 결론**: 자료가 가설을 지지하는지 판단하고 한계를 적는다.

## 주요 학습 분야

| 분야 | 핵심 탐구 주제 |
|---|---|
| 물리학 | 운동, 힘, 에너지, 전기와 파동 |
| 화학 | 물질의 구조, 상태 변화, 화학 반응 |
| 생명과학 | 세포, 유전, 생명 시스템과 생태계 |
| 지구과학 | 지구 내부, 대기와 해양, 천체와 우주 |
