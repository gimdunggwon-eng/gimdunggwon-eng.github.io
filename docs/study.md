# 📚 공부 공간

과목별 개념 학습, 자료 정리, 문제 풀이와 오답 복습을 한곳에서 관리하는 개인 학습실이다.

각 과목은 **개념 이해 → 예시 확인 → 스스로 설명하기 → 문제 적용 → 오답 복습** 순서로 공부한다. 단순히 내용을 옮겨 적는 데 그치지 않고, 왜 그런지 자신의 말로 설명할 수 있도록 기록한다.

## 공통 학습 관리

### 공부 기록

| 날짜 | 과목 | 학습 단원 | 이해도 | 다음에 할 일 |
|---|---|---|---|---|
| YYYY-MM-DD | 과목명 | 단원·주제 | 충분 / 보통 / 복습 필요 | 복습할 개념 또는 문제 |

### 오답 정리 원칙

1. 정답만 옮기지 않고 처음 풀이에서 잘못 판단한 지점을 찾는다.
2. 실수를 개념 부족, 조건 누락, 계산·표현 실수 등으로 구분한다.
3. 올바른 풀이를 다시 작성하고, 비슷한 문제에 적용해 본다.
4. 며칠 뒤 해설을 보지 않고 다시 풀어 본다.

### 자료를 정리할 때 지킬 기준

- 사실·정의·공식은 신뢰할 수 있는 교재나 공신력 있는 자료를 바탕으로 확인한다.
- 출처가 필요한 내용은 자료명과 링크를 함께 기록한다.
- 서로 다른 설명이 있으면 하나로 단정하지 말고 차이와 근거를 비교한다.
- 아직 확인하지 못한 내용은 추측으로 채우지 않고 확인할 항목으로 남긴다.
