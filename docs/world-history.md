# 세계사 학습실

세계 여러 지역의 역사와 문명 사이의 교류·충돌·변화를 시대별로 정리하는 학습 공간이다.

## 학습의 큰 흐름

- **고대 문명**: 메소포타미아·이집트·인더스·황허 유역의 문명과 지중해 세계
- **고전 고대**: 그리스·헬레니즘 세계와 로마
- **중세 세계**: 유럽의 봉건 사회, 이슬람 세계, 동아시아 여러 왕조와 교역
- **근세 세계**: 르네상스, 종교개혁, 대항해 시대와 세계 교역망의 확대
- **근대 세계**: 시민혁명, 산업혁명, 제국주의와 민족운동
- **현대 세계**: 세계대전, 냉전, 탈식민화와 세계화

## 비교하며 공부하기

| 비교 주제 | 살펴볼 질문 |
|---|---|
| 국가와 권력 | 통치자는 어떤 제도와 사상으로 권력을 정당화했는가? |
| 경제와 교역 | 생산·교역 방식은 사회를 어떻게 바꾸었는가? |
| 종교와 사상 | 종교와 사상은 정치·문화에 어떤 영향을 주었는가? |
| 전쟁과 외교 | 전쟁의 원인과 결과, 국제 질서의 변화는 무엇인가? |
| 교류와 이동 | 사람·물자·기술·지식은 어떻게 이동했는가? |

## 학습 기록 양식

각 주제마다 시대적 배경, 주요 사건, 관련 지역, 원인과 결과, 사료의 관점을 구분해 기록한다. 유럽 중심의 서술에 치우치지 않도록 아시아·아프리카·아메리카의 역사도 함께 살펴본다.

**학습 원칙:** 특정 문명을 다른 문명보다 우월하거나 열등하다고 단정하지 않고, 각 사회의 역사적 조건과 상호 교류를 함께 분석한다.
