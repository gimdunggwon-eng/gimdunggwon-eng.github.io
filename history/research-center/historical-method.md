# 역사 연구 방법론

## 1. 연구의 기본 원칙

역사 연구는 과거에 발생한 사실을 자료를 통해 확인하고, 그 사실이 발생한 배경과 의미를 분석하는 학문적 활동이다.

역사 연구에서는 사료의 신뢰성, 시대적 맥락, 사건의 인과관계를 종합적으로 검토해야 한다.

## 2. 연구 진행 과정

### STEP 1. 연구 주제 선정
- 연구할 사건이나 인물을 선정한다.
- 연구 대상의 시대와 범위를 설정한다.
- 핵심 연구 질문을 작성한다.

### STEP 2. 자료 수집
- 역사 사료 수집
- 학술 논문 조사
- 전문 역사서 확인
- 공공 역사기관 자료 확인

### STEP 3. 자료 검증
- 작성 시기와 작성자 확인
- 자료의 목적과 성격 파악
- 원자료와 후대의 해석 구분
- 다른 자료와 교차 검증

### STEP 4. 역사적 분석
- 시대적 배경 분석
- 사건의 원인과 전개 분석
- 역사적 결과 분석
- 여러 관점 비교

### STEP 5. 결론 작성
- 확인된 사실 정리
- 연구 질문에 대한 답변
- 역사적 의의와 한계 제시
- 추가 연구 과제 도출

## 3. 사료 비판

### 외적 비판
자료 자체의 진위와 출처를 검토한다.

- 누가 작성했는가?
- 언제 작성되었는가?
- 원본인가, 후대의 복사본인가?
- 자료의 제작 및 전승 과정은 어떠한가?

### 내적 비판
자료에 기록된 내용의 신뢰성을 검토한다.

- 작성자는 사건을 직접 경험했는가?
- 작성자의 관점과 목적은 무엇인가?
- 당시의 상황을 정확히 반영하는가?
- 다른 자료와 내용이 일치하는가?

## 4. 역사 연구의 주의사항

- 확인되지 않은 주장을 사실로 기록하지 않는다.
- 사료에 나타난 기록과 실제 역사적 사실을 동일시하지 않는다.
- 현대의 가치관만으로 과거를 단순하게 평가하지 않는다.
- 특정 국가나 집단의 관점만으로 역사를 설명하지 않는다.
- 사료가 부족한 부분은 연구의 한계로 명시한다.

## 5. 최종 연구 평가 기준

| 평가 항목 | 확인 사항 |
|---|---|
| 정확성 | 사실에 오류가 없는가? |
| 근거성 | 신뢰할 수 있는 자료를 사용했는가? |
| 논리성 | 원인과 결과가 연결되는가? |
| 객관성 | 여러 관점을 검토했는가? |
| 완성도 | 결론이 연구 질문에 답하는가? |
| 출처 | 자료의 출처가 명확한가? |
